# Iteration history

These dated notes record research, reproductions, rejected experiments and the
evidence behind earlier decisions. They are not current instructions: the
[agent guides](../agents/README.md) own current decisions, and the newest user
correction wins when a note disagrees. Read a note when you need the reasoning
behind a rule or want to avoid repeating a failed approach.

Repository paths inside these notes were updated to the 2026-10-24 layout so
their links resolve. Receipts, versions and results remain as originally
recorded. The [codebase map](../agents/codebase-map.md#2026-10-24-layout-migration)
lists the earlier paths.
