# Native focus and synthetic controller verification

The exported graphical suite intermittently reported an Xbox movement failure after a successful keyboard trial. At injection, native window/application focus and production intent were correct. Authority moved one tick (0.15 units), then stopped. A separate exported focused controller run reproduced a later Switch direction failure; source and other exported runs passed the same 749 controller checks.

Per-frame probes isolated the cause: at a failed direction sample the raw axes and seat binding remained correct, both native focus indicators were false, and production intent was neutral. A read-only macOS `NSWorkspace` observer independently recorded the foreground application changing from Blast Circuit to SystemUIServer and later Ghostty/Arc. This establishes actual desktop focus interruption; it does not establish a controller mapping, SDL, network or movement defect. The product correctly suppresses input while unfocused.

Controller QA now checks real native window/application focus around each measured frame. Observed focus loss invalidates the complete controller scenario attempt, releases inputs, restores physical discovery and begins a fresh scenario after real OS activation and a 500 ms stable focus interval. Recovery is capped at three attempts and reported explicitly in the trace. Invalid attempts' assertion/capture entries are removed from the final result counts, while their trace remains available. Functional assertion failures never retry. Repeated focus interruption still fails explicitly rather than pretending to validate held input in the background.

No production focus flag, input guard or device behavior is bypassed. Existing tests of focus-loss suppression, release/rearm and continuous stick restoration remain in the scenario. The private desktop runner should remain isolated during input verification; a user switching applications can invalidate these checks even when game input is functioning correctly. The synthetic suite does not claim fresh physical button testing.
