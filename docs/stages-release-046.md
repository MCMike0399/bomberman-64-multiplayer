# Stage expansion release candidate

Status: source candidate prepared; not yet published or deployed.

The candidate is version **0.46.0**, build **58**, protocol revision **7**.
The four added battle arenas complete the original ten-stage roster; Circuit
Garden remains the separate training arena. Every arena receives a High-first
visual review and appropriate Medium/Low translations.

## Compatibility decision

Revision 7 records the expanded strict peer-stage contract: four new accepted
stage identifiers and their cell validation paths. State envelopes retain their
existing required fields; Gutter's bounded current object is additive and
optional. The exact admission token is `7/0.46.0/58`, so previous published
clients cannot join this release's server/peer rooms. Local play is unaffected.
The protected rollout and signed updater preserve the existing release policy.
